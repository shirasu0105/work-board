# ロードマップ v1.0.0

`docs/requirements.md` で定義した「仕事効率化Webアプリ」初版（個人利用・ローカル起動）の MVP を段階的に構築する。各フェーズは `npm run dev` を立ち上げて目に見える動作確認ができる粒度で区切る。`/implement-phase` を実行すると次の TODO フェーズが自動着手される。

## 設計トーン

- **UI トーン**は `DESIGN.md`（Notion 風・温かいニュートラル＋細い border）に従う。フォントは `Inter` 系の system-ui フォールバック、アクセントは Notion Blue `#0075de`。
- `docs/design-references/reference/` の JSX / HTML / `screens-*.jsx` は**情報設計と画面構成のラフ参考**であり、ピクセル一致やワイヤーフレーム独自の手書き風スタイル（Yomogi フォント・SVG ザラつきフィルタ等）は実装に持ち込まない。
- 表示・出力言語は **日本語固定**。
- データは SQLite（Prisma 推奨）でローカル永続化。認証・複数ユーザーは対象外。

## 対象スコープ（要件書 §11 より）

- 含める: ホーム / Inbox / カテゴリ / プロジェクト / タスク / 待ち状態 / メモ＋種別 / 日次ジャーナル
- 簡易実装: Someday / Maybe、週次レビュー、タスク検索・絞り込み、メモ検索・絞り込み
- 対象外: 認証・タグ・添付・通知・AI 連携・繰り返しタスク・優先度・タスク依存

## 想定する各フェーズ完了時の「触れる範囲」

| フェーズ完了時 | dev 上で触れること |
|---|---|
| Phase 1 | サイドナビから全 9 画面の空雛形へ遷移できる。レイアウト崩れなし |
| Phase 2 | カテゴリの新規追加・編集・並び替え・表示 ON/OFF・永続化 |
| Phase 3 | タスクの追加・編集・ステータス変更・完了（リスト表示） |
| Phase 4 | Inbox にメモ風にポンポン入れる→タスク/プロジェクト/Someday へ振り分け。プロジェクトに紐づくタスク管理 |
| Phase 5 | タスクを待ち状態に切替（待ち相手・理由必須）→ 待ち専用一覧で待ち日数確認。かんばん表示で 5 列横並び |
| Phase 6 | メモを 5 種別から選んで作成。種別変更で入力フォームが切り替わる。一覧で時系列確認 |
| Phase 7 | ホーム画面で「今日やること」「待ち」「Inbox 件数」「進行中Pj」「最近メモ」を一望。日次ジャーナルで明日のタスクを選ぶと翌日のホームに反映 |
| Phase 8 | 週次レビュー 6 ステップを順番に実施。タスク/メモを条件絞り込み。空状態・エラー表示の整備 |
